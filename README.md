# HiddenKernel · PLM Repository

Repositorio comunitario para PS5 Payload Manager y catálogo de homebrew para Pegasus DL.

## Fuentes y contenido de terceros

HiddenKernel no está afiliado con Sony, PKG-Zone ni con los desarrolladores de las aplicaciones enlazadas.

- Los nombres, marcas, iconos y demás materiales pertenecen a sus respectivos titulares.
- HiddenKernel no aloja automáticamente los PKG importados desde PKG-Zone: el catálogo enlaza a la fuente externa.
- Las portadas automáticas de PKG-Zone tampoco se copian ni se vuelven a publicar en este repositorio; se referencian mediante su URL original.
- Cuando existe una fuente oficial del desarrollador, se prioriza sobre mirrors de terceros.
- La importación automática está limitada a categorías de homebrew, utilidades y emuladores. No se incorporan automáticamente juegos comerciales, DLC, updates, Retail PKG ni contenido comercial equivalente.

Si eres desarrollador o titular de derechos y quieres que una entrada se corrija o se retire, abre un issue en este repositorio indicando el Title ID o el nombre de la aplicación.

## Catálogos

- `payloads.json`: payloads y utilidades para PS5 Payload Manager.
- `pegasus-homebrew.json`: catálogo de homebrew/utilidades para Pegasus DL.
- `pegasus-homebrew-manifest.json`: procedencia e integridad de las entradas del catálogo.
